# Долг Кошачьей Души

HD-2D игра на Godot 4.7.2 (GDScript, Forward+).

## Как запустить
1. Скачать Godot 4.7.2 (stable, standard): https://godotengine.org/download/archive/4.7.2-stable/
2. Открыть в Godot файл `Game/CatsSoulDebt/project.godot`. Первый импорт ассетов занимает несколько минут.
3. F5 — запуск с главного меню.

## Сборка для проверки
Готовый Windows-билд лежит в разделе Releases: [все сборки](https://github.com/Ladan444/cats-soul-debt/releases).
Скачать архив, распаковать, запустить `CatsSoulDebt.exe`. Каждая сборка — отдельный тег `build-ГГГГ-ММ-ДД-vX.Y`.

## Где что
- `Game/CatsSoulDebt/` — проект Godot (сцены, скрипты, ассеты).
- `Tools/` — генераторы уровней и утилиты (Python 3 + Pillow, скрипты для Godot).
- `Литература/` — лор, сценарий Главы 1, спецификации; `CANON.md` — главный источник правды по сюжету.
- `Проект/` — дорожная карта, команда, маркетинг, журнал разработки (`PROGRESS.md`).
- `CLAUDE.md` — правила работы и карта проекта (для людей тоже полезно прочитать).
