# Чеклисты релиза: itch.io и Steam

**[ПРЕДЛОЖЕНИЕ]**, составлено 2026-11-05. Ведёт чат «Стратегия и издание». Ничего не отправляется и не публикуется без автора. Контекст дедлайна — ROADMAP.md, «Предложение: релиз 25 декабря».

## A. Демо / Глава 1 на itch.io

**От автора (только он):**
- [ ] Аккаунт itch.io (создаёт сам), имя проекта и адрес страницы.
- [ ] Решение: цена (предложение — «бесплатно» или «плати сколько хочешь», минимум 0), тип проекта (Downloadable), платформа Windows.
- [ ] Первый полный плейтест главы, одобрение сборки.
- [ ] Нажать «Опубликовать» (я не публикую).

**Сборка:**
- [ ] Windows .exe + .pck в zip, проверено на чистой машине без Godot.
- [ ] Версия в названии файла, например `CatsSoulDebt_Ch1_v0.1.zip`.
- [ ] Обучение, сохранение, настройки, выход работают; экран «Авторы» полон (LEGAL.md).
- [ ] Выбор языка RU/EN.

**Страница:**
- [ ] Название, короткое описание (1–2 строки), полное описание RU/EN.
- [ ] Обложка 630×500 (рекомендация itch.io; сверить при загрузке), 3–5 скриншотов, 1 GIF боя.
- [ ] Теги: pixel art, action-adventure, story rich и т. п.
- [ ] Системные требования, управление (клавиатура/геймпад).
- [ ] Раскрытие ИИ-контента: арт частично из генераций ИИ — указать честно (проверить, есть ли у itch.io отдельная отметка; не придумываю — уточнить при создании страницы).
- [ ] Ссылка на Telegram/обратную связь для отзывов (канал выбирает автор).
- [ ] Цель: 20–50 игроков и отзывы (критерий этапа 2).

## B. Страница Steam

**Сроки (Steamworks, partner.steamgames.com):**
- Ревью страницы — обычно 3–5 рабочих дней, подавать минимум за 7 дней до нужной даты.
- Ревью сборки — 3–5 рабочих дней, закладывать 7; страницу нужно отправить на ревью раньше сборки.
- Страница «Скоро» — не менее двух недель до релиза.
- Direct: $100 за приложение, платит админ аккаунта, не кошельком; возврат при выручке $1 000.
- Обратный счёт для релиза 25.12 в Steam: страница видна с ~10 дек, отправлена ~1 дек, Direct оплачен до ~20 нояб. Это очень плотно — см. вывод в ROADMAP.

**Материалы:**
- [ ] Капсулы (размеры взять из Steamworks на момент создания: главная, малая, вертикальная, шапка библиотеки, логотип).
- [ ] Трейлер 30–60 с, 5+ скриншотов, описание RU/EN, теги, системные требования.
- [ ] Страница создана в Steamworks: аккаунт, налоговая и банковская анкета (для РФ — уточнить, см. LEGAL.md).
- [ ] Прописаны системные требования и поддержка геймпада.

**Раскрытие ИИ-контента (Steamworks Content Survey):**
- Опрос делит ИИ на «созданный заранее» (pre-generated: арт, код, звук — на этапе разработки) и «на лету» (live-generated).
- Для «заранее» требуется заверение, что в игре нет незаконного или нарушающего права контента; раскрытие показывается на странице игры.
- В игре сейчас: арт из генераций (arena.ai) и код с помощью Claude — всё pre-generated. Live-generated нет.
- Игру нужно заранее привести в такой вид, чтобы заверение было правдивым: см. вопрос по правам на арт в LEGAL.md.

**Фестивали и вишлисты:** страницу открывать ради вишлистов как можно раньше после готового трейлера; Next Fest — после демо на Steam (этап 4).
