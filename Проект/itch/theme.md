# Тема страницы itch.io (Edit theme)

Палитра из PROJECT_BIBLE.md: тёплый таверный оранжевый на глубоком фиолетово-ночном фоне (Брод → озеро). Custom CSS не нужен (его включают только по запросу в поддержку).

| Параметр | Значение | Откуда |
|---|---|---|
| Background color | `#1B1526` | глубокий фиолетовый, ночь/озеро |
| Text color | `#F1E4CC` | пергамент журнала |
| Link color | `#FFB45A` | свет свечи |
| Button color | `#C9622B` (текст `#FFF3DC`) | черепица таверны |
| Header/panel color | `#2A2036` (текст `#F1E4CC`) | |
| Layout | Sidebar (скриншоты справа) | |
| Banner | `img/banner_1500x300.png` | |
| Background image | не нужен | |
| Header font | Pixelify Sans (запас: Press Start 2P) | пиксельный, как Public Pixel |
| Text font | PT Sans (запас: Noto Sans) | читаемый для длинного текста |

Шрифты игры (Public Pixel, First Time Writing) в itch не подключить (только Google Fonts), поэтому близкие. **Поддержку кириллицы выбранных шрифтов проверить в редакторе: я не проверял.**
