- Git: `C:\Program Files\Git\cmd\git.exe` (в PATH старых терминалов может не быть). Репозиторий автора — `C:\Users\Ladan444\The cat's soul debt` (внутри зеркало папки проекта, `.gitignore`: `.godot`, `Builds`, редактор Godot, скриншоты, `*.blend1`). Работаем в папке на рабочем столе; после каждого законченного шага — `powershell -File Tools/backup.ps1 "что сделано"` (зеркалирует robocopy и коммитит).
- Обработка ИИ-арта: `python Tools/sprite_pipeline.py "Арт/Генерации/<файл>" --name <имя> --palette <ключ>`; палитры в `Tools/palettes.json` (из SPRITE_SPECS). Результат — `Арт/Обработано/`, в игру копировать в `Game/CatsSoulDebt/assets/sprites/<персонаж>/`. Нужен `PYTHONIOENCODING=utf-8` в PowerShell.
- Пересборка всех спрайтов из генераций и копирование в игру: `powershell -File Tools/rebuild_all.ps1` (новые генерации вписывать в список `$jobs`; файл сохранять в UTF-8 с BOM — иначе PowerShell 5.1 ломает кириллицу в путях).
- Уменьшение — «по большинству» (каждый пиксель исходника сначала в палитру, итоговый пиксель = самый частый цвет блока); `accents` в palettes.json — мелкие важные цвета (глаза, шрамы), которые побеждают при доле ≥ 20 %. Тёмные цвета палитры подбирать по температуре генерации (тёплые/холодные), иначе крупные области уходят в чужой цвет.
- Опции `sprite_pipeline.py` для боя: `--cell-w 96` (ячейка 96×64 под меч и дугу взмаха; ступни и центр те же), `--ref-frame N` (рост задаёт кадр N, где оружие не торчит за силуэт — для атак), `--anchor body` (выравнивание по корпусу — для атак и всего, где меч поднят над головой), `--grid` (лист-сетка: строки сохраняются), `--flip 10,11` (отразить кадры), `--smooth 9` (сгладить слишком детальную генерацию; фон заливается контуром). Палитру можно снять с генерации — медианным квантованием (так сделана `drowned`).
- Ещё опции: `--cell-h 80` (меч над головой; ступни на 4 px выше низа ячейки), `--rows N` (резать сетку на N равных полос, если капли/брызги склеивают строки), `--holes-tolerance 3` (убрать чисто белый фон внутри дуги взмаха, не трогая белую шерсть Рэя). Лист Рэя для боя — ячейка 96×80.
- GIF строки листа: `python Tools/sheet_gif.py <лист> --cell-w 96 --cell-h 80 --row 0`.
- Шрифты: интерфейс — Public Pixel; журнал — First Time Writing (`assets/fonts/first_time_writing/`, импорт со сглаживанием, в коде FontVariation с embolden 0.7).
- Рост в `--height`: Рэй 48, Вельмор 56, Лиара 46. Для тёмных персонажей (Вельмор) добавлять `--holes` — убирает просветы фона между прядями; для белой шерсти Рэя не включать.
- Превью: `python Tools/preview_characters.py ray velmor liara` (виды + ходьба, GIF).
- Иконки предметов и скиллов: `python Tools/icon_pipeline.py "Арт/Генерации/<лист>" --names icon_a,icon_b,...` → 14×14 в `assets/ui/` поверх заглушек (палитра `icons`). Промпты — `Литература/ICON_PROMPTS.md`. Заглушки рисует `Tools/ui_atlas.py`; уже существующие иконки предметов/скиллов он не трогает (перерисовать заглушки — `--force`).
- Кадры анимации: `sprite_pipeline.py ... --height <рост вида из базового листа> --anchor head` (выравнивание по голове, чтобы кадры не дёргались), затем `python Tools/set_anim_row.py <кадры> <лист анимаций> --anim walk --dir side` вставляет их в строку листа.

## Мир вокруг Брода (по концепту автора)

Порядок в рельефе: высоты → площадки/террасы/дороги → вода (берега, затем русло и дно — иначе выравнивание засыпает русло). Пустышки `poi-<id>`, `lantern-NN`.
- Мир — основная карта игры (решение автора 2026-10-29): старый Брод и тестовые карты убраны, в мастер-меню — «Ивовый Брод».
- Референсы мест автора — `Арт/Концепты/Места/` (настроение и композиция; детали — по канону). Места строят `poi_*()` в build_world.py; рендеры мест: `exec(..., {"__name__": "__main__", "RENDER_POIS": True, "POI_NAMES": [...]})` → `world_poi_<id>.png` (камера над землёй у места). Общие рендеры — `RENDER_ONLY` (отдельным вызовом: вместе со сборкой не укладывается во время ожидания MCP). Входы шахты/пещер — на краю гор (`MOUNTAIN_EDGE`), иначе площадка уходит на 40–100 м вверх.

Дороги — отдельный меш `Roads`: ленты вдоль сглаженной (Chaikin) линии, профиль поперёк — `ROAD_PROFILE` (цвет в вершинах, UV: v — метры вдоль), над водой лента рвётся; мощёный тракт — камень на грань, провалы `paved_gap`. Мелочи — `details()`: фонари душ (`soul_lantern`: посох-крюк, подвесной латунный фонарь, материалы `glow_material`; точки `fx-soul-lantern-NN`, `npc-guide-NN`, `spawn-spirit-NN`), указатели, вёрстовые камни, стога, телеги, поленницы, руины (`RUIN_TOWERS`/`RUIN_WALLS` в world_layout.py, кладка `masonry`). Рендеры деталей и итоговые — инлайн-скриптом с `{"__name__": "relief"}` (функции без сборки) + `render_setup()`. Вид сверху для карты журнала — `Арт/Blender/world_map_top.png` + `.json` (границы в метрах).
- Мир в Godot (черновик рядом со старым Бродом): сборка в Blender пишет `Арт/Blender/world_heights.bin` (float32, строка — Blender y), `world_terrain.json`, карты смешивания `world_splat_a/b/c.png` (1 px = 2 м; C.b — снег, шейдер `terrain_splat` с `splat_step`); glb без рельефа — `exec(..., {"__name__": "__main__", "EXPORT_ONLY": True})` → `assets/levels/world.glb`. Одевание (`world_level.gd`, таблица `DRESS`): дороги — шейдер `road_ribbon` (цвет профиля × текстура колеи по UV ленты), остальное с цветом вершин — `wall_xray` с `use_vertex_color` и текстурой детализацией (`detail_mean` — средняя яркость, считает скрипт). ## Структура проекта
- `scenes/levels/`, `scenes/player/` — сцены; `scripts/<область>/` — скрипты; `assets/sprites/` — спрайты.
- Ввод (`project.godot`): движение — WASD, стрелки, левый стик (крестовина отдана предметам); `dash` — пробел/ПКМ/B; `run` — Shift/L3; `attack` — ЛКМ/J/X; `interact` — E/A; `skill_1..4` — Q R F C / Y LB RB RT; `item_1..4` — 1–4 / крестовина ↑→↓←; `inventory` — Tab/I/View; `journal` — M; `pause` — Esc/Start; `ui_tab_prev/next` — Q/E, LB/RB; `ui_accept` — Enter/пробел/A и `ui_cancel` — Esc/B (переопределены: у движка нет кнопок геймпада для них)
- Интерфейс (UI_SPEC.md): автозагрузка `PlayerState` (`scripts/core/player_state.gd`) — HP, энергия души, отметки смерти, гелиосы с потерями по сложности, демо-скиллы и предметы; HUD (`scripts/ui/hud.gd`) только читает его сигналы. UI рисуется в UI-пикселях внутри `UIScaler` (целочисленный масштаб, холст 640×360 при ×3; `min_canvas` не даёт окну вылезти за экран — по умолчанию 400×264, у книги больше). Тема — `assets/ui/theme.tres` (собирает `Tools/godot/build_ui_theme.gd`), графика — `Tools/ui_atlas.py` → `assets/ui/`. Шрифт Public Pixel (8/16 px, импорт без сглаживания), подписи в ячейках — `TinyFont` 3×5.
- Отладка HUD — в мастер-меню (O): урон, смерть, +25 гелиосов, новый спуск, Перепутье.
- Анимации персонажей: `scripts/animation/directional_sprite.gd` (класс `DirectionalSprite`). В игре у Рэя лист боя 96×80 (`ray_combat.png`, см. «Бой»); исходные листы ходьбы: ячейки 64×64, столбцы — кадры (до 4), строки — анимация × направление (down, up, side) в порядке `idle, walk, run, dash`. Временные листы собирает `Tools/make_placeholder_anim.py`.

## Соглашения
- Спрайты персонажей: рост около 48 px, 4 направления (влево = отражённое вправо). Арт генерируется ИИ и дорабатывается вручную.
- Окружение: 3D-геометрия с пиксельными текстурами (фильтр nearest).
- Управление: клавиатура, мышь и геймпад одновременно — каждое действие в InputMap должно иметь привязки для клавиатуры и геймпада, и для мыши там, где это осмысленно (движение мышью не делаем).
- 2.5D: 3D-мир, персонажи — `Sprite3D` с `billboard = Y`, `shaded = true`, `alpha_cut = discard`, фильтр nearest (пиксель-арт).
- Камера «диорамы»: фиксированный наклон, FOV ~30, DOF ближнего и дальнего плана.
- Атмосферу локаций задавать через `WorldEnvironment` (туман, glow) по палитрам из PROJECT_BIBLE.
- Комментарии и имена узлов в сценах можно писать по-русски, идентификаторы в коде — на английском.
- Все персонажи — антропоморфные звери.
