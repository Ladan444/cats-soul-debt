# Охота

- Клаус отдаёт лук: старый охотничий лук лежит в заимке у [[Охотничий лагерь|Охотничьего лагеря]]. Шаги: поговорить → лагерь (Утопшие) → лук → наконечник Вальдо → вернуться.
- Выбор: вернуть наконечник Клаусу (амулет «Выдох охотника») или оставить себе; лук достаётся в обоих случаях.
- Решение автора (2026-10-27): дальнее оружие — лук, открывается квестом Клауса. Механика лука — чат combat.
- Идентификатор: `klaus_bow`.
