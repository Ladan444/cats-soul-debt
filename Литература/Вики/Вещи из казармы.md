# Вещи из казармы

- Три личные вещи павших из казармы — для прощания на берестяном челне, или продать графу (60 гелиосов).
- Идёт после «Возвращения пустоты». Судьба самих душ остаётся открытой.
- Идентификатор: `oda_relics`. Данные квеста — `village_quests.gd` в проекте.
