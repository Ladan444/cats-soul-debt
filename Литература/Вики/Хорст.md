# Хорст

- Кузнец, старый барсук, бывший оружейник гарнизона.
- Потерял в [[Ночь Рубежа]] племянника-подмастерья Бранко. Тайно хранит слепок офицерской печати третьей роты с чужими следами резца.
- Квесты: [[Клещи оружейника]], [[Сталь третьей роты]]. Кузница меняет меч на улучшенные.
- Закаляет меч с ростками [[Каменная ива|каменной ивы]].
- Улучшает оружие: «оружие + материал» ([[Крафт]]).
