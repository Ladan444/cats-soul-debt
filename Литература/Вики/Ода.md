# Ода

- Лодочница, выдра; готовит погребальные лодки для павших. Смотрительница пристани в третьем поколении.
- Прячет под настилом лодку отца, ушедшего в [[Ночь Рубежа]] за ранеными, — не может её отпустить.
- Квесты: [[Возвращение пустоты]], [[Вещи из казармы]].
