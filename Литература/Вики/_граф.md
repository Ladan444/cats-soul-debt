# Цвета графа Obsidian

Окно графа → значок ⚙ → «Группы» → «Новая группа»; запрос и цвет:

| Запрос | Что красит |
|---|---|
| `tag:#открыто` | нерешённые вопросы (поставь первой в списке — красный) |
| `tag:#персонаж` | персонажи |
| `tag:#житель` | жители Брода |
| `tag:#место` | места |
| `tag:#понятие` | понятия |
| `tag:#глава` | главы |
| `tag:#квест` | квесты жителей |
| `tag:#хаб` | хабы |

Статус (канон / предложение / открыто) — свойство `статус` каждой заметки.
Чтобы видеть только вики: в фильтре графа — путь `Вики`. Включи «Стрелки» и «Названия».
