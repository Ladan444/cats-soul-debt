# Каменная ива

- Растёт в [[Лесное святилище|Лесном святилище]], которое старше Рубежа. Серый росток, листья твёрдые как сланец; не гниёт в воде.
- Рабочая версия лора (автор, 2026-10-27): иву посадили древние звери, чтобы удержать воду озера; корни тянутся к [[Тихая Вода|Тихой Воде]]. Пока [[Хозяин Тихой Воды|Хозяин]] спит, ива отдаёт ростки; при его пробуждении вянет.
- Игровой предмет `stone_willow_sprout`: материал улучшения меча гарнизона у [[Хорст|Хорста]] (7 штук по главам, по BALANCE.md).
- Рядом живут [[Флинги]].

**Источник:** [[CANON]] §1 «Окрестности» (**[ПРЕДЛОЖЕНИЕ]**)
