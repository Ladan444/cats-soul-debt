# UI SPEC: интерфейс «Долга Кошачьей Души»

Статус: **черновик на согласование.** После одобрения реализуется в Godot по шагам (раздел 7).
Лор — по `CANON.md`, визуал мира — по `PROJECT_BIBLE.md`.

Решения автора (2026-10-20):
- Порядок работы: сначала этот документ, потом экраны по одному, начиная с хотбара.
- «Жизни» = полоса HP + 9 отметок смерти за спуск.
- «Энергия» = энергия души: тратится на рывок и скиллы, восстанавливается со временем.
- Графика: рамки, панели и полосы рисую кодом; иконки предметов и скиллов генерируются ИИ по промптам (до тех пор — заглушки).
- Журнал — **журнал Рэя** с вклеенными чужими страницами.
- Хотбар: **4 скилла + 4 предмета**.
- Экипировка компактная: оружие, плащ, доспех, амулет, 2 реликвии.
- Стиль — **дерево + пергамент**.
- Приняты предложения: отметки смерти — «искры души», реликвии — вещи павших, вкладка «Души», чужие почерки в журнале, места смертей на карте, хотбар скрыт в таверне, главное меню — живая диорама.
- Бой — удары мечом плюс скиллы (скиллы проработаем позже).
- Валюта — **монета Гелиос**.
- Скиллы Рэй получает из **собранных душ**: душа даёт ему силу своего владельца.
- Шрифт интерфейса — **Public Pixel Font** (GGBotNet, CC0, кириллица, сетка 8×8).

Пометки: **[ПРЕДЛОЖЕНИЕ]** — моё, ждёт одобрения; **[ОТКРЫТО]** — не решено.

## 1. Общие принципы

### Идея
Интерфейс — это вещи из мира гарнизона: деревянная планка с кожаными ремнями, полевой журнал солдата, приказ на рваной бумаге. Никакого «стеклянного» UI. На экране игры интерфейса как можно меньше: главное — диорама.

### Палитра интерфейса
Отдельная от палитр персонажей, но в тех же тонах.

| Роль | HEX | Где |
|---|---|---|
| Тёмное дерево | `#2E1D14` | рамки, тени панелей |
| Дерево | `#4F3322` | основа хотбара и меню |
| Светлое дерево | `#76503A` | фаски, блики |
| Кожа | `#5C3A2A` | ремни, вкладки |
| Пергамент | `#E6D6B0` | страницы, ячейки |
| Пергамент, тень | `#C9B387` | заливка ячеек, края |
| Чернила | `#2A1E18` | текст на пергаменте |
| Зелёный гарнизона | `#4E6253` | акценты (цвет плаща Рэя) |
| Латунь | `#C9A040` | заклёпки, выделение, выбранный пункт |
| HP | `#B23A3A` / тень `#6E2024` | полоса здоровья |
| Энергия души | `#8FD8D0` / тень `#3E7E86` | полоса энергии (призрачный бирюзовый) |
| Фиолетовый Тихой Воды | `#7A3CB0` | использованные отметки смерти, эффекты печати |

### Пиксельная сетка и масштаб
- UI рисуется пиксель-артом в «UI-пикселях». **[ПРЕДЛОЖЕНИЕ]** Масштаб ×3 при 1080p: виртуальный холст 640×360. Это мельче, чем ×4, поэтому помещается больше текста, но пиксели ещё заметны.
- В настройках — «Масштаб интерфейса» ×2 / ×3 / ×4, только целые значения, чтобы пиксели не расплывались.
- Панели — 9-slice: углы и края фиксированы, середина тянется. Все рамки генерирует скрипт `Tools/ui_atlas.py` (будет), Godot собирает их в `Theme`.

### Шрифты
- **Подписи клавиш и счётчики в ячейках** — свой крошечный шрифт 3×5 (`scripts/ui/tiny_font.gd`) на тёмной плашке: 8×8 слишком крупен для ячейки 22×22.
- **Интерфейс:** Public Pixel Font — `Game/CatsSoulDebt/assets/fonts/public_pixel/PublicPixel.ttf`, https://ggbot.itch.io/public-pixel-font (CC0, 1324 глифа, русский есть). Моноширинный, сетка 8×8, использовать только кратными размерами: 8 UI-пикселей (обычный текст), 16 (заголовки).
- **[ОТКРЫТО]** «Рукописные» шрифты для журнала — по одному на почерк (раздел 4). Кандидаты можно взять из той же подборки CC0-шрифтов с кириллицей: https://itch.io/c/3694742/cyrillic-cc0-pixel-fonts (monogram, Pizel, Not Jam Laika 11, Nb Pixel Font Bundle).

### Управление в меню
- Клавиатура: стрелки/WASD — выбор, Enter/E — подтвердить, Esc — назад.
- Геймпад: крестовина/стик — выбор, A — подтвердить, B — назад, LB/RB — вкладки.
- Мышь: наведение и клик; колесо — прокрутка.
- Выбранный элемент всегда виден: латунная рамка и лёгкое покачивание.

## 2. HUD и хотбар

### Расположение
Внизу по центру, одна компактная планка. Остальной экран свободен.

```
                 ✦ ✦ ✦ ✦ ✦ ✦ ✦ ✦ ✦      ← 9 отметок смерти
     ♥ ▰▰▰▰▰▰▰▱▱▱         ◈          ▰▰▰▰▰▰▰▰▱▱ ◇   ← HP | эмблема | энергия души
 ┌────┬────┬────┬────┐  ┌──┐  ┌────┬────┬────┬────┐
 │ Q  │ E  │ R  │ F  │  │  │  │ 1  │ 2  │ 3  │ 4  │
 └────┴────┴────┴────┘  └──┘  └────┴────┴────┴────┘
       скиллы                       предметы
```

### Элементы
1. **HP** — красная полоса слева с иконкой кошачьего сердца. При уроне «съеденная» часть сначала становится светлой и догоняет за полсекунды — так виден размер удара.
2. **Энергия души** — бирюзовая полоса справа. Тратится на рывок и скиллы, восстанавливается со временем. Если энергии не хватает, ячейка скилла темнеет, а полоса коротко мигает.
3. **9 отметок смерти** над планкой. Каждая отметка — светлая искра души. При смерти одна искра «тонет»: темнеет до фиолетового цвета Тихой Воды (в лоре каждая смерть оставляет часть души в воде). После девятой — переход на Перепутье. Отметки сбрасываются в начале нового спуска.
4. **Центральная эмблема.** **[ПРЕДЛОЖЕНИЕ]** Печать Рубежа. В спуске под ней — название зала. Позже эмблема может отражать состояние печати.
5. **4 ячейки скиллов** (слева) и **4 ячейки предметов** (справа). В углу ячейки — клавиша или кнопка геймпада; иконка подстраивается под последнее использованное устройство. Перезарядка — тёмная заливка, уходящая снизу вверх. У предметов — счётчик количества. Скиллы — это силы собранных душ (раздел 3, вкладка «Души»).
6. **Гелиосы** — счётчик монет в правом верхнем углу: иконка монеты и число. При подборе число коротко подпрыгивает. Виден и в таверне — там торговля.

### Привязки
| | Клавиатура / мышь | Геймпад |
|---|---|---|
| Атака мечом | ЛКМ, J | X |
| Рывок | пробел, ПКМ | B (уже есть) |
| Взаимодействие | E | A |
| Скиллы 1–4 | Q, R, F, C | Y, LB, RB, RT |
| Предметы 1–4 | 1, 2, 3, 4 | крестовина ↑ → ↓ ← |

Рывок, атака и взаимодействие — на самых удобных кнопках, скиллы — на оставшихся. E отдано взаимодействию, поэтому скиллы — Q, R, F, C.

Клавиши 1–3 сейчас заняты отладочной сменой облика — она переедет на F1–F3.

### Поведение
- **В таверне-хабе** хотбар скрыт, видны только подсказки взаимодействия и гелиосы.
- **Подсказка взаимодействия** — маленькая плашка над объектом: «E — Говорить».
- **Полоса босса** — сверху экрана, имя на пергаментной ленте.
- **Мало HP** — обесцвечивание и помехи по краям экрана (из PROJECT_BIBLE). Сам HUD при этом не мигает, чтобы не раздражать.
- **Призрачное состояние (Главы 2–5):** HUD слегка просвечивает и подрагивает. Когда Покупатель близко, по планке проходит «пульс» в такт сердцу, а отметки смерти дрожат.
- **Потери при смерти.** Теряется доля гелиосов, найденных в этом спуске: **50 % / 75 % / 90 %** в зависимости от сложности. При потере над счётчиком всплывает «−N» фиолетовым и монеты «тонут».
- **Утерянная добыча.** Часть потерянного остаётся лежать на месте смерти. В мире — горсть монет в фиолетовой лужице, слабо светится; на карте журнала — значок монеты рядом с крестиком смерти. Подобрал — монеты вернулись. На месте остаётся **случайная доля потерянного — от 35 до 75 %** (решение автора, 2026-10-22). **[ОТКРЫТО]** Пропадает ли кучка при следующей смерти до подбора (как в souls-играх).

## 3. Меню персонажа и инвентарь

Открывается клавишами Tab / I или кнопкой View на геймпаде. Игра на паузе. Выглядит как кожаный полевой планшет с пергаментными страницами.

```
 ┌──[Снаряжение]─[Предметы]─[Души]─[Ключевое]───────────────────────┐
 │                               │                                   │
 │   [плащ]   ┌────────┐ [амулет]│  ┌──┬──┬──┬──┬──┬──┐               │
 │            │  Рэй   │         │  ├──┼──┼──┼──┼──┼──┤  ┌──────────┐ │
 │   [оружие] │ (вид   │ [доспех]│  ├──┼──┼──┼──┼──┼──┤  │ описание │ │
 │            │ спереди)│        │  └──┴──┴──┴──┴──┴──┘  │ предмета │ │
 │ [реликвия] └────────┘[реликвия]                        └──────────┘ │
 │   HP 80/100 · Душа 60 · Сила · Защита                               │
 └──────────────────────────────────────────── LB/RB — вкладки ───────┘
```

### Левая страница — Рэй
- В центре — спрайт Рэя, вид спереди, idle-анимация. Он меняется вместе с надетым: плащ, оружие.
- Слоты вокруг: **оружие, плащ, доспех, амулет, реликвия ×2**.
- Реликвии — вещи павших товарищей: пассивные бонусы плюс короткая история владельца в описании. Это связывает экипировку с лором о погибшем гарнизоне.
- Под портретом — характеристики: HP, энергия души, урон меча, защита. Окончательный набор — когда проработаем бой.
- В углу страницы — гелиосы.

### Правая страница — вкладки-закладки
1. **Снаряжение** — то, что можно надеть.
2. **Предметы** — расходники (припарки и настойки, например рецепты Лиары), материалы.
3. **Души** — собранные души павших товарищей. Каждая — имя, рота, обрывок воспоминания и **сила владельца**: она становится скиллом Рэя. Отсюда скиллы назначаются в хотбар. Позже — кому отдать душу: графу или освободить. Скилл при этом **остаётся**: Рэй уже впитал умение. Душа после этого показывается во вкладке как «отданная» или «освобождённая», с последней записью о её судьбе.
4. **Ключевое** — сюжетные вещи и улики. Их нельзя выбросить; есть ссылка «Открыть в журнале».

- Сетка ячеек **6×3** с прокруткой. Справа — описание выбранного предмета: иконка крупно, название, тип, текст, действия («Надеть», «В хотбар», «Выбросить»).
- Назначение в хотбар: выбрать предмет или скилл → «В хотбар» → выбрать ячейку. Мышью — перетаскиванием.
- Отдельной вкладки «Навыки» нет: скиллы живут во вкладке «Души».

## 4. Журнал Рэя: записи и карты

Открывается клавишей M (J занята атакой) или через меню паузы на геймпаде (View уже открывает меню персонажа). Это разворот потрёпанного блокнота: чернила на пергаменте, как на референсе skullfungus.

### Идея
Журнал ведёт Рэй: короткие солдатские записи, рисунки карт, списки. Внутрь вклеены **найденные страницы чужим почерком**:
- записи Лиары — писаря гарнизона: аккуратный почерк, медицинские пометки;
- приказы и рапорты командиров: казённый почерк, печати;
- обрывки карт других солдат.

Разные почерки — часть расследования: по ним игрок узнаёт, кто что знал о ночных вылазках Рэя.

### Разделы (закладки сбоку)
1. **Записи** — хроника по главам и найденные страницы. Новые записи помечены латунной скрепкой.
2. **Карты** — карты залов (подробно ниже).
3. **Люди** — досье на персонажей; пополняется по мере сюжета. **[ПРЕДЛОЖЕНИЕ]** Портрет — маленький чернильный набросок.
4. **Улики** — **[ПРЕДЛОЖЕНИЕ]** страница расследования: улики, вклеенные кусочками, и связи между ними, проведённые чернилами. Сюда же ведут ссылки из вкладки «Ключевое».
5. **Бестиарий** — **[ПРЕДЛОЖЕНИЕ]** заметки о врагах и стражах в духе skullfungus: рисунок, повадки, уязвимости. Открываются после встречи.

### Карты
Карта каждого зала рисуется **от руки**, комната за комнатой, как на референсе: левая страница — нумерованные заметки, правая — план.

- **Состояния комнаты:**
  - **неизвестна** — пусто;
  - **намечена** — карандашный эскиз; появляется, если найден обрывок чужой карты;
  - **исследована** — чернильный рисунок плюс номер и заметка Рэя на левой странице.
- **Значки:** фонари душ (зажжён / не зажжён), сундуки, запертые двери, стражи, улики, места смертей.
- Места смертей отмечаются маленьким крестиком с номером отметки (1–9) — в духе рогалика игрок видит, где ему тяжело.
- Отметка «Рэй здесь» — значок кошачьей лапы.
- Технически: у каждой комнаты свой рисунок (тайл карты) и координаты; журнал собирает лист из тайлов по состояниям. Рисунки комнат можно генерировать ИИ в чернильном стиле или рисовать вручную.

### Почерки и шрифты
| Автор | Стиль |
|---|---|
| Рэй | печатные, угловатые, местами с нажимом |
| Лиара | аккуратный наклонный, мелкие поля с пометками |
| Командиры | казённый, ровный, с печатью внизу |
| Граф | изящный, красными чернилами; появляется поздно и тревожит |

## 5. Главное меню и настройки

### Главное меню
- Фон — живая диорама, а не картинка. Ночной вид на Каменный Рубеж с озером; в окне таверны мерцает свет; камера медленно плывёт.
- Логотип «Долг Кошачьей Души» — латунные буквы на деревянной вывеске, как у таверны.
- Пункты: **Продолжить, Новая игра, Загрузить, Настройки, Авторы, Выход.** «Продолжить» скрыто, если сохранений нет.
- **Новая игра → выбор сложности** на отдельном листе: «Легко / Нормально / Сложно» с описанием (потери гелиосов 50 / 75 / 90 %). Сложность можно сменить в настройках.
- **Сохранение** — пока один слот: «Продолжить» загружает его, «Загрузить» (список слотов) неактивно до появления нескольких сохранений.
- Выбранный пункт — латунная стрелка-коготь слева и лёгкое свечение.

### Меню паузы
Esc / Start. Мир за меню затемняется и размывается. Пункты: Продолжить, Журнал, Персонаж, Настройки, Выйти в главное меню.

### Настройки
Лист рваной бумаги поверх тёмного дерева (референс 4). Вкладки:

1. **Изображение:** разрешение, режим (оконный / без рамки / полноэкранный), вертикальная синхронизация, масштаб интерфейса (×2/×3/×4), яркость, качество теней и тумана.
2. **Звук:** общая громкость, музыка, эффекты, окружение, голоса.
3. **Управление:** схема клавиатуры и геймпада, переназначение клавиш, чувствительность стика, вибрация.
4. **Игра:** язык, скорость текста, тряска камеры, **сила эффектов помех и глитча** (у Рэя-призрака их много, поэтому нужна возможность ослабить), субтитры.

- Каждый параметр: подпись слева, справа — стрелки ◀ значение ▶ или ползунок-ремешок.
- Внизу: «По умолчанию», «Назад». Отдельной кнопки «Применить» нет: изменения применяются сразу, а при закрытии сохраняются в `user://settings.cfg`.
- Сложность — «Легко / Нормально / Сложно» (решение автора), меняется во вкладке «Игра» в любой момент.
- Вкладка «Управление» пока показывает список привязок без переназначения; язык — только русский (решение автора).
- Вкладки переключаются мышью, Q/E или LB/RB.

## 6. Техническая основа в Godot

- Весь UI — `Control` на отдельном `CanvasLayer`, общий `Theme` (`assets/ui/theme.tres`) с 9-slice стилями из атласа.
- Пиксельная чёткость: фильтр nearest, позиции и размеры кратны UI-пикселю, масштаб — целое число.
- Данные отдельно от экранов:
  - `ItemData` — ресурс предмета: иконка, имя, тип, описание, эффекты;
  - `SkillData` — скилл: стоимость энергии, перезарядка;
  - `JournalEntry` — запись: автор/почерк, текст, глава, условие открытия;
  - `MapRoom` — комната карты: рисунок, координаты, состояние.
- Состояние игрока (HP, энергия, отметки смерти, инвентарь) — в автозагрузке `PlayerState`. HUD и меню только читают её и подписываются на сигналы.
- Новые действия ввода (сразу с привязками клавиатуры и геймпада): `skill_1..4`, `item_1..4`, `attack`, `interact`, `inventory`, `journal`, `pause`, `ui_tab_prev/next`.

## 7б. Книга и кнопки для мыши и касания (2026-10-21, решения автора)
Многим проще нажимать кнопки на экране, чем учить клавиши, поэтому всё, что делается клавишей, можно сделать и мышью или пальцем.
- **Одна книга на всё.** Разделы 3 и 4 объединены. Книга: обложка из бордовой кожи с латунными уголками, две кремовые страницы, корешок. Закладки торчат из-за края: слева — Рэя (Снаряжение, Предметы, Души, Ключевое), справа — журнала (Записи, Карты, Люди, Улики, Бестиарий), у каждой своя иконка 10×10; открытая закладка — пергаментная и выдвинута дальше. В правом верхнем углу — красный крестик. Внизу обложки — подсказка картинками клавиш.
- **Управление книгой.** Tab / I / View — разделы Рэя, M — журнал; та же клавиша при открытой книге закрывает её, клавиша другой половины перелистывает. Q/E и LB/RB листают все 9 закладок по кругу. Esc / B, крестик или клик мимо книги — закрыть (в режиме назначения в хотбар Esc сначала отменяет назначение).
- **Страница Рэя:** слева — Рэй, 6 слотов экипировки, характеристики, гелиосы; справа — сетка 6×3 (прокручивается, если вещей больше), хотбар 2×2, описание, кнопки действий.
- **HUD:** в левом верхнем углу — круглые деревянные кнопки «Книга», «Карта» (сразу закладка «Карты»), «Меню»; под каждой — картинка её клавиши. Ячейки хотбара нажимаются мышью и пальцем (в таверне выключены вместе с хотбаром).
- **Крестики** — в паузе, настройках, «Новой игре», «Авторах». Область нажатия крестика больше картинки — для пальца.
- **Картинки клавиш** вместо текста «Q/E — вкладки»: клавиша на тёмной крышке или цветная кнопка геймпада; меняются сами при переключении между клавиатурой и геймпадом.
- **Касание:** кнопки не меньше 20 UI-пикселей; касание работает как мышь (но эмулированная касанием ЛКМ не бьёт).
- **Экранное управление (сделано):** плавающий джойстик в левой части экрана (где коснулись — там центр; в покое полупрозрачный внизу слева, не заходит на хотбар), справа — крупная кнопка «Удар» (меч), «Рывок» (шеврон) и «Действие» (кошачья лапа). Работает мультитач. Появляется само при первом касании экрана и прячется при клавиатуре/геймпаде; при касании подписи клавиш не показываются. Настройка «Игра → Сенсорное управление»: Авто / Всегда / Выкл.
- **Масштаб:** окно не вылезает за экран — если выбранный масштаб слишком большой для окна, он уменьшается (книге нужен холст не меньше 608×344).
